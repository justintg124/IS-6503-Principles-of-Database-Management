# Cutting Edge Analytics — Barbershop Database

## Overview
A relational database project developed for a small barbershop as part of IS 6503: Principles of Database Management class.

The project takes the barbershop's employee, equipment, sales, and training data and organizes it into a structured MySQL database.

## Project Components
- Conceptual, logical, and physical data models
- 7-table relational database
- Primary and foreign key relationships
- Junction tables for many-to-many relationships
- SQL table creation and data insertion
- SQL queries using joins, subqueries, aggregation, CASE statements, and data-integrity checks
- Sample project data
- Normalization
